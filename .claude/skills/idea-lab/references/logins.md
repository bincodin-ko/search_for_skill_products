# 로그인 출처 활용 (Aside, 메인 전용)

검색에 안 걸리는 증거(사장님 카페 본문, 아이보스 질문답변, 인스타·X 운영자 공지, Reddit 댓글, 숨고 커뮤니티)는 로그인해야 보인다. 메인만 Aside로 읽는다. 조사원·하베스터는 Aside를 쓰지 않고, 못 본 출처를 **정확한 URL 또는 사이트+검색어**로 남긴다.

## 규칙 (예외 없음)
- **읽기만 한다.** 글쓰기·댓글·좋아요·팔로우·DM·투표·가입 신청을 하지 않는다. 사용자 이름으로 외부에 남는 행동은 초안까지만
- 로그인·회원가입·본인 인증·CAPTCHA는 사용자가 직접 한다. 메인은 로그인 창을 탭으로 열어 주기만 한다
- 사용자가 로그인 중일 수 있으니 **탭을 한꺼번에 닫지 않는다**(구글 로그인 팝업을 닫아 X 로그인이 끊긴 적이 있다). 내가 연 탭만 닫는다
- 민감한 분야(게이 등)는 부계정을 권한다. 본계정 추천 피드·기록에 흔적이 남는다

## 세션 시작 점검
사이트별로 한 번 열어 로그인 여부를 본다: 로그인 문구(로그인·Log In·계속하기)만 보이면 로그아웃, 로그아웃·받은 편지함·쪽지·받은견적 같은 말이 보이면 로그인. 로그아웃된 곳만 사용자에게 로그인 창을 열어 부탁한다.
기본 목록: X, 인스타그램, 네이버, Reddit, 숨고, 아이보스 (선택: Discord — 서버 가입이 필요해 효용 낮음, 블라인드 — 회사 메일 인증이라 제외)

## 쓰는 곳 네 가지
1. **보류 후보**(`prefilter: hold`) — 1단계에서 메인이 볼 곳을 열어 판정
2. **조사 뒤 로그인 출처** — `LAB gated`로 판정이 바뀔 수 있는 것만 뽑아 읽는다. 로그인 정보는 불편·지불 증거를 **더할 수만** 있고 경쟁 제품을 없애지 못한다. 그래서 경쟁 제품·무료 대체재로 떨어진 것은 다시 보지 않는다
3. **표본 검증 보강** — 4단계 아이디어의 불편 원문이 1건뿐일 때 카페·아이보스 본문으로 채운다
4. **도구 요청 글 하베스트**(메인) — "유료도 상관없고 추천", "is there a tool", "엑셀로 하는데" 같은 글. 글 자체가 불편+지불 의향 증거이고, **댓글이 곧 경쟁 제품 목록**이다(댓글에 추천된 제품이 있으면 빈틈 아님)

## 사이트별 요령 (실측 2026-09-24)
| 사이트 | 방법 | 주의 |
|---|---|---|
| 네이버 카페 | `search.naver.com/search.naver?ssc=tab.cafe.all&query=` 결과의 스니펫과 댓글 미리보기 | 기간 필터(nso)를 붙이면 결과가 비었다. 업체 홍보 글이 많아 경쟁 제품 발견용으로 좋다 |
| 아이보스 | 글 URL(`ab-2110-번호`)을 직접 열면 본문 보임 | 질문답변 목록은 `?page=`가 안 먹는다(1쪽만). 광고 운영·트래픽 조작 질문이 대부분 |
| 인스타그램 | 계정 페이지·게시물의 `og:description`으로 캡션 읽기 | 해시태그 검색은 키워드 검색으로 바뀌어 엉뚱한 글이 섞인다. 운영자 계정을 직접 연다 |
| X | `x.com/search?q=..&f=live`, `article` 텍스트 | 한국어 틈새 검색은 결과가 거의 없다 |
| Reddit | 검색은 `www`, 본문·댓글은 `old.reddit.com` 주소로 | r/smallbusiness 등은 시장조사 글을 금지 — 읽기만 |
| 숨고 | 커뮤니티 글 URL 직접 열기 | |

## 실측 결과 (4회차)
- 조사 때 "로그인 필요"로 남은 206개 중 판정이 바뀔 수 있는 것은 40개(증거 부족 2점). 그중 22개를 로그인 상태로 확인 → **판정이 바뀐 것 0개**. 대신 경쟁 제품이 더 나왔다(일용직 노무 프로그램, 사입 미송 추적 시스템, 악성 리뷰 삭제 대행, 무인매장 CCTV 검색 도구 개발 중)
- 퀴어 파티 운영(i412): 사전예매 개인 계좌이체·현장 카드 불가를 확인(불편 실재). 그러나 행사 규모가 작아 수수료 모델로는 revenue 2
- 쓸모가 컸던 곳: 4단계 아이디어의 원문 보강(i120 아이보스 본문, i140 Reddit), 새 후보의 경쟁 확인(Reddit 댓글)

## 실측 (5회차) — 로그인 출처의 진짜 역할
- **불편 원문 채우기가 1순위.** 관문의 pain(원문 3건)은 공개 검색만으로는 거의 안 채워진다. 네이버 카페 원문 4건으로 i062가 관문 통과, X 원문 2건으로 i140 통과, Reddit r/shopify 원문으로 i390을 여러 나라 대상으로 넓힘
- 발굴용으로는 약하다: Reddit "is there a tool" 글 6개 → 0(댓글에 이미 도구 추천), 보류 후보 4개 → 0
- 인스타: `explore/search/keyword/?q=` 는 **짧은 한 단어**만 결과가 나온다(여러 단어는 0). 게시물은 `og:description`으로 캡션을 읽는다. 한 번에 게시물 10개 이상 열면 120초 제한에 걸린다
- 지식iN은 WebSearch·WebFetch에 안 잡힌다 → Aside로만
- Aside가 꺼지면("Aside isn't running") 사용자에게 다시 켜 달라고 한다. 로그인은 유지된다
