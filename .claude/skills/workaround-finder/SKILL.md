# workaround-finder (막힘 해결 대안 찾기)

목표는 "막혔습니다"로 끝내지 않고, **지금 쓸 수 있는 방법 + 설치하면 풀리는 제품**을 근거와 함께 내놓는 것이다. 확인된 해결법은 `references/known-fixes.md`에 쌓는다.

## 넘지 않는 선

- 사이트의 봇 차단·CAPTCHA·유료벽·지역 제한을 뚫지 않는다. CAPTCHA가 뜨면 그 경로는 버린다
- 이용약관이 금지하는 대량 수집을 권하지 않는다. 공식 API·공식 연동이 있으면 그것을 먼저 권한다
- 비밀번호·API 키·결제 정보를 대신 입력하지 않는다. 사용자가 직접 입력하거나, 비밀번호를 AI에게 보여주지 않는 제품(Vault형)을 권한다
- 설치·설정 변경·유료 결제는 사용자 확인을 받은 뒤에 한다. 설치 파일을 받고 실행하는 것은 사용자가 한다
- 비용이 드는 대안은 "무엇에 얼마가 드는지"를 공식 가격표 기준으로 적는다. 한도(천장)와 실제 비용을 구분해서 설명한다

## 1단계: 막힘 진단

오류 원문을 그대로 인용하고 아래 중 하나로 분류한다.

| 유형 | 예 | 먼저 볼 곳 |
|---|---|---|
| A. Claude Code 내부 한도·설정 | 웹 검색 세션 한도, 권한 거부, 타임아웃, 컨텍스트 | `references/known-fixes.md`, Claude Code 문서(claude-code-guide 에이전트) |
| B. 외부 사이트 접근 | 로그인 필요, CAPTCHA, 지역 제한, 요청 제한(429) | 공식 API·공식 연동, 사용자가 로그인한 브라우저 |
| C. 기능 부재 | "이 도구로는 X를 못 한다" | MCP 서버·CLI·API가 있는 외부 제품 |
| D. 비용·할당량 | API 할당량, 유료 전환 | 무료 제공량, 더 싼 경로, 구독에 포함되는지 |

같은 막힘이 `known-fixes.md`에 있으면 그 해결법부터 쓴다(날짜가 오래됐으면 다시 확인).

## 2단계: 내장 해결책 먼저

외부 제품을 찾기 전에 이미 있는 것으로 풀리는지 본다.
- 설정: `~/.claude/settings.json`의 `env`, 권한 규칙(`update-config` 스킬)
- 세션: 새 세션·`/clear`로 초기화되는 한도인지(작업이 파일에 저장돼 있으면 잃는 게 없다)
- 다른 도구: WebFetch(주소 직접 열기), `claude-in-chrome`(사용자 브라우저), 이미 연결된 MCP 서버(`ListMcpResourcesTool`, 도구 목록)
- 작업 방식: 서브에이전트에 나누기, 배치 크기 줄이기

## 3단계: 외부 개발 제품 조사

내장 해결책이 없거나 약하면 외부 제품을 조사한다. 조사원 에이전트 1명에게 맡겨도 된다(WebSearch가 막혔으면 WebFetch로 공식 문서의 `llms.txt`·docs를 읽거나, 메인이 Chrome으로 검색한다).

**찾아볼 분야 (출발점일 뿐 — 반드시 현재 상태를 확인한다)**
- AI 브라우저·브라우저 에이전트: 로그인한 사이트에서 대신 일하고 MCP로 연결되는 것(예: Aside)
- 검색 API: 웹 검색을 MCP 서버로 붙일 수 있는 것
- 페이지 읽기·크롤링 API: 공식 API가 없는 공개 페이지를 약관 안에서 읽는 것
- 자격 증명: 비밀번호를 모델에 보여주지 않고 로그인만 대신하는 것
- MCP 디렉터리: claude.ai 커넥터 디렉터리, MCP 레지스트리에서 같은 문제를 푸는 서버

**후보마다 모을 것**
- 무엇인지 한 줄, 공식 링크
- 가격: 무료 제공량과 유료 가격(공식 가격 페이지 기준, 확인 날짜)
- Claude Code 연결 방식: MCP 서버(명령·설정 JSON), CLI, API. 공식 문서에서 명령을 그대로 옮긴다
- 자격 증명 처리: 비밀번호·키를 누가 어디에 입력하나, 모델이 값을 보나
- 플랫폼: Windows 지원 여부(사용자 PC는 Windows)
- 약관·위험: 대상 사이트 약관과 충돌하지 않나, 데이터가 어디로 가나
- 확인하지 못한 항목은 "확인 필요"로 표시한다

## 4단계: 비교와 추천

사용자에게는 아래 순서로 보여준다.
1. 막힘 한 줄 요약(원인 포함)
2. 지금 바로 되는 방법(내장)과 한계
3. 외부 제품 비교표: 이름 · 푸는 것 · 가격 · Claude Code 연결 · 자격 증명 · Windows · 출처
4. 추천 1개와 이유(비용·설치 부담·연결 난이도)
5. 할 일 나누기: **사용자가 할 일**(설치, 로그인, 키 발급) / **Claude가 할 일**(`claude mcp add ...`, 설정 변경, 연결 확인)

## 5단계: 적용과 기록

- 사용자가 고른 대안을 적용하고 실제로 되는지 확인한다(MCP 연결 확인, 테스트 호출 1회)
- 새로 확인한 해결법·제품 정보를 `references/known-fixes.md`에 날짜와 출처를 붙여 추가한다. 틀린 것으로 드러난 항목은 고치거나 지운다
- 끝나면 원래 하던 작업으로 돌아간다
